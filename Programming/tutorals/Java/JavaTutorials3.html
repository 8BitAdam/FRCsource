Java variables

Variables are used to store data values in Java. Before you can use a variable, you must declare it.

In Java there are different types of variables. Each type has a specific purpose and behavior.

  • String: Used to hold text like "Hello". String values are surrounded by double quotes.
  • int: Used to hold whole numbers like 123 or -456.
  • float: Used to hold decimal numbers like 3.14 or -2.5.
  • char: Used to hold a single character like 'A' or 'z'.
  • boolean: Used to hold true or false values.
