Java Data types

As explained in the previous chapter, a variable in Java must be a specified data type:

In Java there are different types of variables. Each type has a specific purpose and behavior.

Primitive Data Types

Data types are divided into two groups:

  • Primitive Data Types: - includes byte, short, int, long, float, double, boolean and char
  • Non-Primitive Data Types: - includes strings, classes, interfaces, and arrays
Data Type Description Max value Min value Example
byte 8-bit signed integer 127 -128 byte b = 100;
short 16-bit signed integer 32767 -32768 short s = 10000;
int 32-bit signed integer 2147483647 -2147483648 int i = 100000;
long 64-bit signed integer 9223372036854775807L -9223372036854775808L long l = 100000L;
float 32-bit floating point (IEEE 754) ≈ 3.4028235e38 ≈ -3.4028235e38 float f = 3.14f;
double 64-bit floating point (IEEE 754) ≈ 1.7976931348623157e308 ≈ -1.7976931348623157e308 double d = 3.14159;
boolean Logical type with two values true or false boolean flag = true;
char 16-bit Unicode character '\uffff' (65535) '\u0000' (0) char c = 'A';
