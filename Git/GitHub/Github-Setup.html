Setting Up a GitHub Account

Topic: GitHub account creation · Level: Beginner

Introduction

A GitHub account lets you host code, track projects, collaborate with others, and work with GitHub repositories. This page walks through creating an account and setting up the basic profile options.

Use a strong password and enable two-factor authentication as soon as the account is created.

Sign Up

  1. Go to GitHub’s sign-up page.
  2. Enter your email address.
  3. Create a username and password.
  4. Choose the free plan or another plan that fits your needs.
  5. Complete the verification step if prompted.

Verify Email

After sign-up, GitHub sends a verification email. Open the message and click the verification link to activate the account fully.

Tip: Check spam or junk folders if the email does not appear right away.

Set Up Profile

Recommended profile items

  • Add a profile photo.
  • Write a short bio.
  • Set your display name.
  • Link a website or portfolio if you have one.

Example bio

Student learning Python, Java, web development, and Linux.

Security Options

  • Enable two-factor authentication.
  • Save recovery codes in a safe place.
  • Use a password manager if possible.
  • Review account permissions for connected apps.

Troubleshooting

Did not receive the verification email

Check spam folders, confirm the email address was entered correctly, and request a new verification email if needed.

Username already taken

Choose a different username or adjust the spelling slightly until it is available.

Locked out after sign-up

Use account recovery steps and make sure your email and password are stored securely.
