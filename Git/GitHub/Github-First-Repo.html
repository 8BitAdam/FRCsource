Making Your First GitHub Repository

Topic: GitHub Repositories · Level: Beginner

Introduction

A repository (repo) is where your project lives on GitHub. It stores code, files, and version history. This guide walks through creating your first repository and uploading code to it.

Every project you build on GitHub starts with a repository.

Create a Repository

  1. Log into GitHub.
  2. Click the + icon (top right).
  3. Select New repository.
  4. Enter a repository name.
  5. Choose Public or Private.
  6. (Optional) Add a README file.
  7. Click Create repository.

Initial Setup

git init
git add .
git commit -m "Initial commit"

Then connect your local project to GitHub: 

git remote add origin https://github.com/username/repo-name.git
git branch -M main

Push Code to GitHub

git push -u origin main

This uploads your local project to GitHub for the first time.

Tips

  • Always write a clear README file.
  • Commit often with meaningful messages.
  • Use branches for features.
  • Push regularly to avoid losing work.
