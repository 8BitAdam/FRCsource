Setting Up the Git CLI

Topic: GitHub CLI and PAT authentication · Level: Beginner

Introduction

Git can connect to GitHub over HTTPS or SSH. For HTTPS, GitHub recommends using GitHub CLI or Git Credential Manager to remember credentials. If you authenticate without GitHub CLI, Git uses a personal access token instead of a password. :contentReference[oaicite:1]{index=1}

GitHub recommends fine-grained personal access tokens when possible. Password-based Git authentication is no longer the normal path. :contentReference[oaicite:2]{index=2}

Install GitHub CLI

  1. Install gh on your system.
  2. Open a terminal.
  3. Confirm it works with gh --version.
gh --version

Authenticate with GitHub CLI

The standard command is gh auth login. GitHub CLI can authenticate by browser or by personal access token, and it can also help configure SSH keys. :contentReference[oaicite:3]{index=3} 

gh auth login
This is the easiest option if you want Git to stop asking for credentials all the time. GitHub also recommends Git Credential Manager or GitHub CLI for credential caching. :contentReference[oaicite:4]{index=4}

Use a Personal Access Token

If you clone or push over HTTPS without GitHub CLI, Git will prompt for a username and password. In that case, use your GitHub username and paste your personal access token as the password. GitHub recommends fine-grained tokens where possible. :contentReference[oaicite:5]{index=5}

Create a PAT

  1. Open your GitHub settings.
  2. Go to personal access tokens.
  3. Create a fine-grained token if your use case allows it.
  4. Give it only the permissions you need.
  5. Copy the token and store it securely.
If your organization uses SSO, the token may need to be authorized for that organization before it works there. :contentReference[oaicite:6]{index=6}

Set Git Identity

Git also needs your name and email for commits. Set these once on your machine so your commits are labeled correctly. :contentReference[oaicite:7]{index=7} 

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Troubleshooting

Git keeps asking for a password

Use GitHub CLI or a credential helper such as Git Credential Manager so your token is cached instead of re-entered every time. :contentReference[oaicite:8]{index=8}

Authentication fails on push

Check that the remote URL is correct, that the token has the right permissions, and that you have access to the repository. :contentReference[oaicite:9]{index=9}

Token works on GitHub but not in an organization

The token may need SSO authorization or organization access approval. :contentReference[oaicite:10]{index=10}
