Git Reset

Command: git reset · Topic: Move HEAD or index

Introduction

git reset moves the current branch tip (HEAD) and can modify the index and working tree depending on mode: --soft, --mixed, or --hard.

Syntax

git reset [--soft|--mixed|--hard] <commit>
git reset -- <path>...

Basic Use

# reset HEAD to previous commit but keep changes staged
git reset --soft HEAD~1

# discard working tree changes (dangerous)
git reset --hard HEAD

Troubleshooting

Be careful with --hard as it discards changes. Use git reflog to recover commits if needed.
