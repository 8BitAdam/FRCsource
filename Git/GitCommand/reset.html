Git Reset

Command: git reset · Topic: Move HEAD or index · Level: Intermediate

Introduction

git reset moves the current branch pointer (HEAD) and optionally updates the index and working directory. Its behavior depends on the mode used.

--hard will permanently discard changes—use with caution.

Syntax

git reset [--soft|--mixed|--hard] <commit>
git reset -- <path>...

Basic Use

Undo last commit (keep staged)

git reset --soft HEAD~1

Unstage files (default behavior)

git reset HEAD file.txt

Discard all local changes

git reset --hard HEAD

Examples

Reset to a specific commit

git reset --mixed abc1234

Remove last 2 commits completely

git reset --hard HEAD~2

Troubleshooting

Lost commits

Use git reflog to find and restore previous states.

Accidental hard reset

If recent, recover via git reflog and reset back.
