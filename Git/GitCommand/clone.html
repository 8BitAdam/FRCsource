Git Clone

Command: git clone · Topic: Starting a working area · Level: Beginner

Introduction

git clone is used to make a copy of an existing repository. It downloads the repository history, creates a new local folder, and sets up a remote connection so you can fetch, pull, and push later.

Use git clone when you want to start working from an existing project instead of creating a brand-new repository.

Syntax

git clone <repository-url>

The repository URL can come from GitHub, GitLab, Bitbucket, or another Git server.

Basic Use

The most common use is cloning a remote repository into a local directory. 

git clone https://github.com/username/project-name.git

This creates a new folder named project-name and downloads the repository into it.

Examples

Clone into the default folder

git clone https://github.com/username/project-name.git

Creates a local folder with the same name as the repository.

Clone into a custom folder name

git clone https://github.com/username/project-name.git my-folder

Creates the repository contents inside my-folder.

Clone with SSH

git clone git@github.com:username/project-name.git

Useful when your SSH key is already set up.

Common Options

  • --depth 1 — clones only the latest commit history.
  • --branch <name> — clones a specific branch.
  • --single-branch — clones only one branch instead of all branches.
git clone --depth 1 --branch main https://github.com/username/project-name.git

Troubleshooting

Problem: “Repository not found”

Check the URL, confirm the repo exists, and make sure you have permission to access it.

Problem: Clone is too large

Use a shallow clone with --depth 1 if you only need the latest version.

Problem: Authentication fails

Use the correct HTTPS credentials or set up SSH authentication properly.

Practice

Try cloning a small repository from GitHub, then run: 

cd project-name
git status

This confirms that the repository was cloned successfully and shows the current state.
