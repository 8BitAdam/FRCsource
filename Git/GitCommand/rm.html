Git Rm

Command: git rm · Topic: Removing files · Level: Beginner

Introduction

git rm is used to remove files from your working directory and stage that removal for the next commit. It ensures Git tracks the deletion properly.

Use git rm when you want to delete a file and record that deletion in Git history.

Syntax

git rm <file>

This removes the file from both your filesystem and the staging area.

Basic Use

The most common use is to delete a file and stage that change. 

git rm file.txt

After running this, the file is removed and ready to be committed.

Examples

Remove a file

git rm notes.txt

Deletes notes.txt and stages the deletion.

Remove a file but keep it locally

git rm --cached config.json

Stops tracking the file but keeps it on your system.

Remove a folder

git rm -r folder-name

Deletes a directory and all its contents.

Common Options

  • --cached — removes the file from Git but keeps it locally.
  • -r — removes directories recursively.
  • -f — forces removal.
git rm -r folder-name

Troubleshooting

Problem: File not removed

Ensure the file is tracked by Git. Untracked files require manual deletion.

Problem: Git refuses to remove file

Use -f if the file has local changes you want to discard.

Problem: File still exists locally

You likely used --cached, which only removes tracking, not the file itself.

Practice

Try removing a file in a test repository: 

git rm file.txt
git status

This should show the file as deleted and staged for commit.
