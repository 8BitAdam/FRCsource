Git Switch

Command: git switch · Topic: Switch branches

Introduction

git switch is a modern command to change branches (safer and clearer than git checkout for branch switching).

Syntax

git switch <branch>
git switch -c <new-branch>

Basic Use

# switch to existing branch
git switch main

# create and switch to a new branch
git switch -c feature

Troubleshooting

If switching fails due to uncommitted changes, either commit/stash them or use flags to force (not recommended).
