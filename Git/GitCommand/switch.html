Git Switch

Command: git switch · Topic: Switch branches · Level: Beginner

Introduction

git switch is a modern, safer command for changing branches. It separates branch switching from file operations, improving clarity over git checkout.

Prefer git switch for branch operations and reserve git checkout for file-level actions.

Syntax

git switch <branch>
git switch -c <new-branch>
git switch -d <start-point>

Basic Use

Switch to existing branch

git switch main

Create and switch to new branch

git switch -c feature

Examples

Switch to previous branch

git switch -

Create branch from specific commit

git switch -c new-branch abc1234

Troubleshooting

Uncommitted changes block switch

Commit or stash changes before switching branches.

Branch not found

Use git branch or git branch -a to verify available branches.
