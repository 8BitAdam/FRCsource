Git Add

Command: git add · Topic: Staging changes · Level: Beginner

Introduction

git add is used to stage changes before committing them. It tells Git which files or file changes you want included in the next commit.

Use git add after editing files and before running git commit.

Syntax

git add <file>

You can add one file, multiple files, or all changes in the current folder.

Basic Use

The most common use is to stage a single file or all modified files. 

git add index.html
git add .

After staging, the changes are ready to be committed.

Examples

Stage one file

git add README.md

Adds only README.md to the staging area.

Stage all changes

git add .

Adds all new and modified files in the current directory and below.

Stage all tracked changes

git add -u

Stages modifications and deletions to files that Git already knows about.

Common Options

  • . — stages everything in the current directory.
  • -A — stages all changes, including deletions.
  • -u — stages modifications and deletions for tracked files only.
git add -A

Troubleshooting

Problem: File is not added

Make sure the file path is correct and that the file is inside the repository.

Problem: Wrong files were staged

Use git status to check the staging area, then remove files from staging with git restore --staged <file>.

Problem: Changes still do not show up

Confirm the file is saved before running git add.

Practice

Try editing a file and then staging it: 

git status
git add .
git status

The second git status should show the files as staged.
