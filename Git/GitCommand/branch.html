Git Branch

Command: git branch · Topic: Manage branches

Introduction

git branch lists, creates, renames, and deletes branches. It does not switch branches by default (use git switch or git checkout to move).

Syntax

git branch
git branch <name>
git branch -d <name>
git branch -m <old> <new>

Basic Use

List branches and create a new one:

git branch        # list local branches
git branch feature  # create branch 'feature'

Examples

# delete a branch
git branch -d feature

# rename current branch
git branch -m new-name

Options

  • -a — list both local and remote branches
  • -r — list remote branches
  • -D — force-delete branch

Troubleshooting

If a delete fails, ensure the branch is fully merged or use -D to force.
