Git Branch

Command: git branch · Topic: Manage branches · Level: Beginner–Intermediate

Introduction

git branch is used to list, create, rename, and delete branches. It does not switch branches; use git switch or git checkout for that.

Branches allow parallel development without affecting the main codebase.

Syntax

git branch
git branch <name>
git branch -d <name>
git branch -m <old> <new>

Basic Use

git branch        # list branches
git branch feature  # create new branch

Examples

Delete a branch

git branch -d feature

Rename current branch

git branch -m new-name

Options

  • -a — show all branches (local + remote)
  • -r — show remote branches only
  • -D — force delete branch

Troubleshooting

Branch won't delete

Ensure it is merged or use -D to force deletion.

Wrong branch renamed

Use git branch to verify current branch before renaming.
