Git Pull

git pull is a convenience command that fetches from and then merges (or rebases) the specified remote branch into your current branch.

Syntax

git pull [options] [ [...]]

Common Use

# fetch and merge remote main into current
git pull origin main

# use rebase instead of merge
git pull --rebase origin main

Tips

  • Prefer git fetch + inspect + git merge/rebase when you want more control.
  • If you have local changes, stash them (git stash) before pulling.
