Git Merge

Command: git merge · Topic: Join histories

Introduction

git merge combines changes from one branch into another. It creates a merge commit when histories have diverged or a fast-forward if possible.

Syntax

git merge <branch>
git merge --no-ff <branch>
git merge --abort

Basic Use

# merge feature into main
git checkout main
git merge feature

Examples

# create explicit merge commit
git merge --no-ff feature

# abort merge in progress
git merge --abort

Troubleshooting

When conflicts occur, resolve the files, add them, and commit. Use git status to inspect the state.
