Git Merge

Command: git merge · Topic: Join histories · Level: Intermediate

Introduction

git merge integrates changes from one branch into another. Depending on history, it performs either a fast-forward merge or creates a merge commit.

Merges preserve full history, making them safer but sometimes noisier than rebases.

Syntax

git merge <branch>
git merge --no-ff <branch>
git merge --abort

Basic Use

# merge feature into main
git checkout main
git merge feature

Examples

Force a merge commit

git merge --no-ff feature

Abort an in-progress merge

git merge --abort

Troubleshooting

Merge conflicts

Resolve conflicting files, run git add, then complete the merge with git commit.

Unexpected merge result

Check commit history with git log --graph to understand branch structure.
