Git Status

Command: git status · Topic: Viewing repository state · Level: Beginner

Introduction

git status shows the current state of your repository. It tells you which files are modified, staged, or untracked, and what branch you are on.

Use git status frequently to understand what Git is tracking and what will be included in your next commit.

Syntax

git status

This command does not modify anything; it only displays information.

Basic Use

The most common use is simply checking what has changed. 

git status

It will list:

  • Staged files (ready to commit)
  • Modified files (not staged)
  • Untracked files

Examples

Check repository state

git status

Displays all current changes and file states.

After adding files

git add .
git status

Shows which files are staged for commit.

After modifying files

git status

Shows which files have been changed but not yet staged.

Common Options

  • -s or --short — shows a compact output.
  • -b — shows branch information.
  • --ignored — shows ignored files.
git status -s

Troubleshooting

Problem: File not showing

The file may be ignored by a .gitignore file.

Problem: Too much output

Use git status -s for a shorter, cleaner view.

Problem: Confusing file states

Pay attention to labels like “staged” vs “not staged” to understand where changes are.

Practice

Try modifying a file and checking its status: 

git status
git add file.txt
git status

Observe how the file moves from “modified” to “staged”.
