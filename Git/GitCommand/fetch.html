Git Fetch

git fetch downloads objects and refs from another repository. Unlike git pull, it does not merge — it only updates remote tracking branches.

Common Usage

# fetch all remotes
git fetch --all

# fetch single remote
git fetch origin

Examples

# update your remote tracking branches
git fetch origin

# then inspect differences before merging
git log HEAD..origin/main --oneline

Notes

  • Use git fetch when you want to inspect upstream changes before integrating them.
  • After fetch, merge or rebase manually, e.g. git merge origin/main.
