Git Tag

Command: git tag · Topic: Tags

Introduction

git tag creates, lists, or deletes tags which are convenient labels for specific commits (commonly used for releases).

Syntax

git tag            # list tags
git tag -a v1.0 -m "Release 1.0"
git push origin v1.0

Examples

# create annotated tag
git tag -a v1.2 -m "Version 1.2"

# push a single tag
git push origin v1.2

Troubleshooting

Tags are local until pushed. To remove a remote tag, use git push --delete origin v1.2.
