Git Tag

Command: git tag · Topic: Tagging commits · Level: Beginner

Introduction

git tag assigns a fixed label to a specific commit. Tags are most commonly used to mark release points such as v1.0.

Tags do not move—they always reference the exact commit they were created on.

Syntax

git tag
git tag -a <name> -m "message"
git tag -d <name>

Examples

Create annotated tag

git tag -a v1.0 -m "Release 1.0"

Push a tag

git push origin v1.0

Push all tags

git push --tags

Troubleshooting

Tag not on remote

Tags must be pushed manually using git push origin <tag>.

Delete remote tag

git push --delete origin v1.0
