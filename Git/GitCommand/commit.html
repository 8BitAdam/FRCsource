Git Commit

Command: git commit · Topic: Record changes

Introduction

git commit records staged changes to the repository as a new commit with a message and metadata.

Syntax

git commit -m "message"
git commit --amend
git commit -a -m "message"

Basic Use

git add .
git commit -m "Add feature X"

Examples

# amend last commit message
git commit --amend -m "New message"

# commit all tracked changes (skip add)
git commit -a -m "Update"

Options

  • -m — provide a commit message inline
  • --amend — modify the most recent commit
  • -a — stage tracked files before committing

Troubleshooting

If your commit fails due to conflicts, resolve them and add the files, then commit.
