Git Commit

Command: git commit · Topic: Record changes · Level: Beginner

Introduction

git commit records staged changes as a snapshot in the repository history. Each commit includes a message, author, timestamp, and a reference to previous commits.

Commits should be small, focused, and have clear messages.

Syntax

git commit -m "message"
git commit --amend
git commit -a -m "message"

Basic Use

git add .
git commit -m "Add feature X"

Examples

Amend last commit

git commit --amend -m "New message"

Commit tracked changes

git commit -a -m "Update"

Options

  • -m — inline commit message
  • --amend — modify last commit
  • -a — auto-stage tracked files

Troubleshooting

Commit fails due to conflicts

Resolve conflicts, stage files, then commit again.

Forgot to add files

Run git add before committing or use -a for tracked files.
