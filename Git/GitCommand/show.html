Git Show

Command: git show · Topic: Show commit details · Level: Beginner

Introduction

git show displays information about objects (commits, tags, blobs) — commonly used to show the details and patch introduced by a specific commit.

Use git show <commit> to inspect a commit's metadata and the diff it introduced.

Syntax

git show [options] <object>
git show --name-only <commit>
git show <commit>:path/to/file

You can show the commit's message, author, date, and the diff for the changes it introduced.

Basic Use

Show the most recent commit: 

git show HEAD

Show a specific commit's patch and metadata: 

git show a1b2c3d

Examples

Show commit with file list only

git show --name-only a1b2c3d

Displays which files were modified by the commit.

Show contents of a file at a commit

git show a1b2c3d:README.md

Prints the file version from that commit.

Show patch in a specific format

git show --pretty=email a1b2c3d

Outputs commit information in email-friendly format.

Common Options

  • --name-only — show file names changed by the commit.
  • --stat — show a summary of changes.
  • --pretty=<format> — format commit metadata.
git show --stat a1b2c3d
git show --pretty=format:"%h - %an, %ar : %s" a1b2c3d

Troubleshooting

Object not found

Make sure the commit hash or object name is correct. Use git log to find commits.

Large output

Pipe output to a pager (default) or limit with options like --name-only or --stat.

Practice

Inspect the last commit and view the files changed: 

git show --name-only HEAD
git show --stat HEAD~1
