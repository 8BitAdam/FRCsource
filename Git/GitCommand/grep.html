Git Grep

Command: git grep · Topic: Searching in repository · Level: Intermediate

Introduction

git grep searches for patterns in tracked files in the repository. It's faster than external grep tools for many Git-aware scenarios and can search across commits and branches.

Use git grep to find code occurrences across the project history or current tree.

Syntax

git grep [options]  [--] [...]
git grep  $(git rev-list --all)

You can combine git grep with commit ranges and use it in scripts to search historical commits.

Basic Use

Search for a pattern in the working tree: 

git grep "TODO"

Search in a specific path: 

git grep "init" -- src/

Examples

Search across all branches

git rev-list --all | xargs git grep "deprecatedFunction"

Find occurrences of a function across every commit.

Show file names only

git grep -l "password"

Lists files containing the pattern.

Context lines

git grep -n -C3 "main"

Shows line numbers and 3 lines of context around each match.

Common Options

  • -n — show line numbers.
  • -i — case-insensitive search.
  • -l — list file names containing matches.
  • -C<n> — show n lines of context.
git grep -n --ignore-case "TODO"
git grep -l "password"

Troubleshooting

No matches found

Ensure the files are tracked by Git; untracked files aren't searched by default.

Searching history is slow

Limit the rev-list or the path scope, or use optimized scripts when searching very large histories.

Practice

Try finding TODO comments and listing files that contain them: 

git grep -n "TODO"
git grep -l "FIXME"
