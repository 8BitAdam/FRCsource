Git Log

Command: git log · Topic: Viewing commit history · Level: Beginner

Introduction

git log shows the commit history for a repository. It lists commits in reverse chronological order, along with metadata like author, date, and commit message.

Use git log to explore the history of changes and find commits relevant to debugging or review.

Syntax

git log [options] [] [--] [...]
git log --oneline
git log --graph --decorate --all

Common options allow compact output, pretty formats, and graphical commit trees.

Basic Use

Show recent commits in one-line format: 

git log --oneline -n 10

Show a decorated graph of all branches: 

git log --graph --decorate --all

Examples

Show commits for a file

git log --follow -- path/to/file

Tracks renames and shows commits that touched the file.

Search commit messages

git log --grep="fix memory leak"

Find commits with messages that match the given pattern.

Show changes introduced by a commit

git show

Shows the diff and metadata for a single commit.

Common Options

  • --oneline — compact one-line per commit.
  • --graph — show a textual commit graph.
  • --author=<pattern> — filter commits by author.
  • --since/--until — time-based filtering.
git log --oneline --author="Alice"
git log --since="2 weeks ago"

Troubleshooting

Too many commits

Use -n, time filters, or path limits to make output manageable.

Renames not shown

Use --follow when viewing history for a single file to follow renames.

Practice

Explore recent commits and filter by author or date: 

git log --oneline --since="1 week ago"
git log -S"search term" -- path/to/file
