Git Rebase

Command: git rebase · Topic: Reapply commits

Introduction

git rebase reapplies commits from one branch onto another base tip. It rewrites history and is often used to keep a linear history.

Syntax

git rebase <base>
git rebase --interactive <base>
git rebase --abort

Basic Use

# rebase feature onto main
git checkout feature
git rebase main

Examples

# interactive rebase to squash commits
git rebase -i HEAD~4

# abort a rebase in progress
git rebase --abort

Troubleshooting

Resolve conflicts as they appear, use git rebase --continue, or abort with --abort.
