Git Rebase

Command: git rebase · Topic: Reapply commits · Level: Intermediate–Advanced

Introduction

git rebase reapplies commits from one branch onto another base commit, rewriting history to create a linear commit sequence.

Avoid rebasing shared/public branches—it rewrites history and can break collaborators.

Syntax

git rebase <base>
git rebase -i <base>
git rebase --abort
git rebase --continue

Basic Use

# rebase feature branch onto main
git checkout feature
git rebase main

Examples

Interactive rebase (cleanup commits)

git rebase -i HEAD~4

Continue after resolving conflicts

git add .
git rebase --continue

Troubleshooting

Merge conflicts during rebase

Resolve conflicts, stage files, then run git rebase --continue.

Need to cancel rebase

Use git rebase --abort to return to the previous state.
