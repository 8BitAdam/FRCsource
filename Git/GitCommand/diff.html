Git Diff

Command: git diff · Topic: Viewing changes · Level: Beginner

Introduction

git diff shows the differences between commits, commit and working tree, etc. It's the primary tool for examining what changed in your code.

Use git diff before committing to review changes, or compare branches to inspect what will be merged.

Syntax

git diff [options] [ []]
git diff [--] [...]
git diff ..

Commonly used with commit ranges, branch comparisons, or files to limit output.

Basic Use

Show unstaged changes: 

git diff

Show staged changes that will be in the next commit: 

git diff --staged

Examples

Compare two branches

git diff main..feature-branch

Shows changes in feature-branch that are not in main.

Show changes in a single file

git diff HEAD -- src/app.js

Shows differences between the working copy and HEAD for a specific file.

Show changes between two commits

git diff a1b2c3d..d4e5f6g

Shows the diff from commit a1b2c3d to d4e5f6g.

Common Options

  • --staged — show staged changes.
  • --name-only — show only names of changed files.
  • --stat — show a summary of changes with file stats.
  • --color-words — show changes inline as words.
git diff --stat main..feature-branch

Troubleshooting

Diff is too large to read

Use --stat or restrict to a directory/file to make output manageable.

File shows as renamed/removed unexpectedly

Check rename detection options and ensure paths are correct when comparing across histories.

Practice

Try making a small change and use git diff and git diff --staged to observe differences. 

echo "debug" >> README.md
git diff README.md
git add README.md
git diff --staged README.md
