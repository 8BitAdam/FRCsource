Git Mv

Command: git mv · Topic: Renaming or moving files · Level: Beginner

Introduction

git mv is used to move or rename a file inside a Git repository. It updates Git’s tracking so the rename is recorded as part of the next commit.

Use git mv when you want Git to understand that a file was moved or renamed.

Syntax

git mv <old-path> <new-path>

The command can rename a file, move it to another folder, or do both at the same time.

Basic Use

The most common use is to rename a file. 

git mv oldname.txt newname.txt

This stages the rename automatically, so you do not need to run git add afterward.

Examples

Rename a file

git mv notes.txt journal.txt

Changes the file name while keeping it tracked by Git.

Move a file into a folder

git mv image.png assets/image.png

Moves the file into the assets folder and stages the move.

Move and rename at the same time

git mv old-folder/file.txt new-folder/new-file.txt

Relocates the file and gives it a new name in one command.

Common Options

  • -f — forces the move if the destination already exists.
  • -n — performs a dry run without making changes.
  • -k — skips files that cannot be moved instead of stopping.
git mv -f oldname.txt newname.txt

Troubleshooting

Problem: Git says the file was not found

Check the source path carefully. The file name and folder path must be exact.

Problem: The destination already exists

Use a different name or use git mv -f if overwriting is intentional.

Problem: The move did not show up in status

Make sure you used git mv instead of moving the file only through your file manager.

Practice

Try renaming a file inside a repository: 

git mv file1.txt file2.txt
git status

This should show the rename as a staged change.
