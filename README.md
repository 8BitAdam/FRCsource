# CORE/CORE2062 Archive

CORE/CORE2062 Archive is currently a single student-led knowledge archive for FIRST Robotics Competition
teams, focusing on programming and scouting and occasionally covering controls/electrical and outreach topics.
It is designed to be beginner-friendly and easy to reference during build season.

## What This Covers

- Programming (Java,C++,Python, basic logic, WPILib concepts)
- Scouting data concepts and strategy
- Controls and driver-related topics
- Electrical basics and best practices
- Light marketing and outreach guidance

This is not a replacement for official FIRST documentation, but a
student-friendly supplement.
